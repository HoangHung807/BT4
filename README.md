# TechReview — Website mẫu tối ưu GEO

Project mẫu: trang tĩnh HTML/CSS/JS cho "TechReview" — đánh giá, so sánh và tư vấn chọn điện thoại.

## Cấu trúc

```
techreview/
  index.html
  article.html
  faq.html
  css/style.css
  js/main.js
  images/
  robots.txt
  sitemap.xml
  README.md
```

## Chạy local

1. Mở thư mục `techreview` trong VS Code.
2. Mở `index.html` bằng Live Server hoặc mở trực tiếp file trong trình duyệt.

## Kiểm tra responsive

1. Mở DevTools → Toggle device toolbar.
2. Kiểm tra ở các kích thước mobile/tablet/desktop.

## Thay domain & Triển khai

1. Thay URL trong meta `canonical`, `sitemap.xml` và JSON-LD.
2. Upload files lên hosting tĩnh (Netlify, Vercel, GitHub Pages).
3. Bật HTTPS trên hosting.

## Submit & Kiểm tra

1. Gửi sitemap tới Google Search Console và Bing Webmaster.
2. Kiểm tra Schema với Rich Results Test và Schema Validator.
3. Chạy PageSpeed Insights.

## Kiểm thử AI Search

Hướng dẫn và bộ truy vấn kiểm thử có trong báo cáo `report.md`.
